# CRM Assistant AI Agent

Учебный практический проект: Интеллектуальный AI-ассистент для CRM-системы на базе LangChain и OpenAI API.

## 🚀 Функционал
- Get Order Status: Проверка статуса заказа по ID.
- Search Delivery Rules (RAG): Поиск правил доставки и возврата с использованием векторной базы знаний (Chroma DB).
- Create CRM Contact: Валидация данных и автоматическое создание контакта в CRM.
- Обработка ошибок и ограничений: Защита от выполнения неразрешенных действий и корректная обработка отсутствующих данных.

## 🛠 Технологии
- Python 3.10+
- LangChain / LangChain OpenAI
- ChromaDB (Векторное хранилище для RAG)
- Pydantic
